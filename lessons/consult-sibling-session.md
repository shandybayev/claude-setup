# Ask a sibling session before guessing, and speak only verified facts

**Rule:** When a request references work, a decision, or a person your session has no record of, check written coordination files first, then ask any sibling session that might know, using the workflow's agent-discovery and messaging tools. Never state an unverified claim as fact; label it as unverified or verify it with a read-only check first.

**Why:** A teammate once referred to "your code change" with no counterpart in the current session's plan. The fix was to research or ask, not to assume, and the human involved asked directly for facts over guesses going forward.

**How to apply:** Before answering a question that references outside context, check the project's coordination or handoff files, then use agent discovery and messaging to ask a sibling session directly. Label anything you have not verified as such. See [[orchestration-workflow]].
